# Runtime, since Stage 3A. The OpenAI-compatible model adapter
# (app/services/llm_openai.py) needs an HTTP client with per-phase timeouts,
# typed transport errors and a pluggable transport for tests. No dependency was
# added to get it: httpx2 was already here for Starlette's TestClient, it is the
# client this Starlette version expects, and it provides all three. No provider
# SDK is installed - the OpenAI chat-completions dialect is spoken directly, so
# the deployment can be vLLM, llama.cpp, TGI or anything else that serves it.
#
# Pinned exactly, with httpcore2 beneath it, since the Stage 3A hardening: the
# adapter enforces MODEL_TIMEOUT_SECONDS as a wall-clock bound by swapping the
# network backend of the connection pools its own client builds, and httpx2
# has no public hook for that. The attributes it uses are private to this
# version; the adapter refuses to start rather than run unbounded if they move,
# and tests/test_stage3a_wallclock_deadline.py pins the behaviour.
httpx2==2.13.1
httpcore2==2.13.1
